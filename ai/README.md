# AI and Question Generation

This directory will contain the design and supporting materials for photo analysis and personalized recall-question generation.

## Planned Responsibilities

- Extract usable cues from personal photos and metadata
- Generate questions that reflect at least two available cues
- Support multiple recall activity types
- Record model inputs, outputs, and evaluation examples
- Document prompt rules, limitations, and privacy considerations

Implementation code may remain inside the Spring Boot application or move to a separate service after the interface is finalized.
