# 사진 업로드 용량 제한

기본값은 사진 한 장 30MB, 전체 multipart 요청 100MB입니다. JPEG·PNG 형식 제한은 유지합니다. 서버 이미지 검증은 Spring multipart 파일 제한과 같은 설정값을 사용합니다.

프런트는 30MB 초과 파일과 합계 100MB 이상 선택을 전송 전에 차단하며 파일명 또는 나누어 업로드하라는 안내를 표시합니다. multipart 구분자·파일명 등 전송 부가정보도 요청 용량에 포함되므로, 합계가 100MB 바로 아래인 경우에도 서버가 거부할 수 있습니다. 이때도 HTTP 413과 사진 크기·개수를 줄이라는 안내를 반환합니다.

Render 백엔드에 `SPRING_SERVLET_MULTIPART_MAX_FILE_SIZE`가 이미 설정되어 있으면 코드의 기본값보다 우선합니다. 파일 제한은 `30MB`, 요청 제한은 `100MB`로 맞추고 재배포합니다. 프런트·백엔드 모두 배포해야 화면의 사전 검사와 서버 제한이 함께 적용됩니다. 키나 비밀번호는 변경할 필요가 없습니다.

검증은 `UploadLimitTest`와 `node --test tests/upload-limits.test.js`로 실행합니다. 서버 단위 테스트는 경계값·설정값 반영·예외 JSON 매핑을 확인하며, 실제 배포 서버의 multipart 전송 검증은 별도로 진행합니다.
