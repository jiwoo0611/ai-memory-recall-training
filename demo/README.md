# Demo

This directory will contain materials for demonstrating one complete user journey.

## Planned Demo Flow

1. A user signs in.
2. The user uploads or selects a personal photo.
3. The service generates a personalized recall question.
4. The user completes a recall activity.
5. The service stores the session and presents feedback.

## Planned Files

- Demo video or GIF
- Sample images that do not contain private information
- Demo scenario and speaking script
- Setup instructions for the demonstration environment
